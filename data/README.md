# NHTSA ADS crash records (2021)

`Incident_Report_2021.csv` is the public Standing General Order crash table used in the paper. Source: [NHTSA Standing General Order on Crash Reporting](https://www.nhtsa.gov/laws-regulations/standing-general-order-crash-reporting).

The file is encoded ISO-8859-1. Narratives marked redacted are dropped before clustering. Work-zone labels are derived from the narrative and roadway description, because the released table does not include a dedicated yes/no work-zone column.
